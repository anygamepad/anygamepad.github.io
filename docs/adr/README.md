# Architecture decision records

An ADR is `proposed` until the project owner accepts it.

One file per decision: `NNNN-title.md` (four-digit number, kebab-case title).

```markdown
# NNNN — Title

- Status: proposed | accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context
## Decision
## Alternatives
## Consequences
```
