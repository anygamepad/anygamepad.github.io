# anygamepad-hid

HID report descriptor parser and report reader for anygamepad: turns the raw
report descriptor of a device into the collections WebHID gives, and its
input reports into raw elements for the mapping engine. Sans-IO, for native
backends and firmware that read HID devices directly (USB host).

Part of [anygamepad](https://github.com/anygamepad/anygamepad.github.io).
Not usable yet: the project is in its first development phase.
