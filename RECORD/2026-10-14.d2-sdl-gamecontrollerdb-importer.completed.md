# D2: SDL GameControllerDB importer

- Status: completed
- Roadmap: ROADMAP/2026-10-14/ (task ID: D2)

## Goal

Bootstrap coverage by converting SDL GameControllerDB entries into
anygamepad profiles, keeping attribution and the license notice.

## Done

- Vendored `gamecontrollerdb.txt` and `LICENSE` unmodified in
  `data/sdl-gamecontrollerdb/` (commit `c1d5289`, 2026-10-02, zlib), with a
  README on updating it.
- `anygamepad_db::sdl::{import, import_line, VENDORED_ATTRIBUTION}`: each
  entry becomes a profile with `source = "sdl-gamecontrollerdb"`,
  `verified = false`, `indices = "sdl"`, the attribution, the family from
  VID/PID, and a match rule with VID, PID, version (when not 0), OS and the
  GUID. `xinput` entries match the XInput backend.
- Targets: `a`/`b`/`x`/`y` by position, `paddle1..4` per SDL3 (right 1,
  left 1, right 2, left 2), `misc1` as mute (Sony), capture (Nintendo),
  share (Microsoft) or `extra_0`, `misc2..6` as `extra_1..5`. Y axes are
  reversed (`~`, or halves swapped); a button or hat on a whole stick axis
  becomes its positive half, as SDL drives it.
- Unknown targets or fields, duplicate targets and invalid profiles are
  errors, so a DB update with new syntax fails the tests.
- Tests: all 2,279 entries import with no error, counts per platform match
  `docs/research/02-sdl-gamecontrollerdb.md`, every profile passes the
  JSON Schema and round-trips through TOML, and the Linux DualShock 4 entry
  (`hid-playstation`, version 0x8111) is the best match for that device.
- Example `sdl_import` prints entries as TOML (all, or one `VID:PID`) to
  start curated profiles.

## Decisions

- Entries are converted in memory, not copied into `data/profiles/`.
  Reason: ADR 0003 has one file per family, and 2,279 generated files
  would drown the curated ones in reviews; D4 embeds the conversion.
- The attribution names the commit and says the data was converted.
  Reason: zlib asks that altered versions be plainly marked.
- No transport in the match rule. Reason: the GUID already holds SDL's bus,
  and a rule `transport = "usb"` would reject dongles, which SDL counts as
  USB.
- Android GUIDs from older SDL versions hold names or hashes; they import
  with the GUID only and match nothing until an Android provider computes
  the same GUID.

## Open questions

- Whether the web bundle should embed SDL entries at all: browsers never
  expose SDL indices. D4 decides (the bundle budget is 128 KiB gzip).
