## Decisions

- CC0 1.0 for reports (owner). Reason: the library embeds profiles built
  from reports; CC0 waives database rights too, so profiles ship under
  MIT/Apache-2.0 and games take on no attribution or share-alike terms.
  The license file lives in `data/reports/`, not at the root, so the code
  does not look CC0.
- The policy is one HTML page of the web app, not Markdown rendered at
  build time. Reason: no new dependency, readable without JavaScript, one
  source, linkable from the issue form and the apps.
- Consent texts live in `docs/privacy/README.md`, not as constants in a
  crate. Reason: W6 and A3 write their own UI; exporting strings from WASM
  grows the bundle; the smoke tests check the texts W6 shows.
- The issue form has no field besides the report and the checkbox.
  Reason: free text is where personal data gets in; comments remain.
- An issue with personal data is deleted, not edited. Reason: anyone who
  can read the repository can read an issue's edit history.
- Curation cites issues by number, never accounts. Reason: the account is
  the only personal data the project handles; nothing of it enters the
  repository.
- Server rules are set now (no stored IPs, daily-keyed HMAC for rate
  limiting kept 24 hours at most, logs without IPs kept 30 days, deletion
  tokens stored hashed, backups kept 30 days, a processor agreement).
  Reason: P2 and P5 design to them instead of retrofitting.
- The privacy link sits next to the environment line, which keeps its own
  element. Reason: the smoke test reads `.environment` as is, and the link
  shows even before the environment is known.
- P3 is marked done although its estimate was 10 days. Reason: its
  deliverables exist and the decisions only the owner could take were
  taken; what remains (below) are owner actions, not P3 work.

## Open questions

- Organization owners must allow deleting issues in the organization's
  repositories; until then a deletion request cannot be honoured. The
  `device-report` label must exist before W6's form is used.
- The policy names the maintainers of the anygamepad organization as
  controller, without a person's name or postal address (owner: GitHub
  only). A named controller may be needed once a server stores data (P5).
- The texts were not reviewed by a lawyer.
- GitHub facts (Pages logs visitor IPs, who can delete issues, edit
  history) come from web search results quoting docs.github.com, which the
  session's network could not open; the links in the policy were not
  opened either. The CC0 legal code was copied from a crate's
  `LICENSE-CC0` (`constant_time_eq` 0.3.1; 7,048 bytes, SHA-256
  `a2010f34...0499`), as creativecommons.org was unreachable.
- JS is at 60.0 of its 64 KiB budget before W6 adds the report store.
