# A1: Desktop app shell

- Status: WIP
- Roadmap: ROADMAP/2026-10-14/ (task ID: A1)

## Goal

The desktop app's shell on the toolkit of ADR 0004: window, system tray,
settings persistence, logging, update check; repaint only on change, near
zero idle CPU.

## Done

- `apps/desktop` (`anygamepad-desktop`, binary `anygamepad`), a workspace
  member: eframe 0.32 (egui), the newest that builds with Rust 1.85.
- Main window: header with the logo's mark and two-tone wordmark, pages
  Devices, Virtual pad, Collection (placeholders naming their tasks),
  Settings, About (versions, links, log file).
- Settings in `settings.toml` (theme, start hidden in the tray, close to
  tray, log level), saved on change through a temporary file; unknown
  keys ignored; an unreadable file is reported and left untouched.
- System tray: `ksni` (StatusNotifierItem, pure Rust) on Linux,
  `tray-icon` on Windows and macOS; Show and Quit; tray settings disabled
  when there is no tray.
- Log to standard error and a file restarted at each launch; per-OS
  settings and log directories (XDG, `%APPDATA%`/`%LOCALAPPDATA%`,
  `~/Library`).
- App and window icon from the logo's mark.
- CI: the desktop app is excluded from the wasm32 jobs.
- Checked: clippy on Linux and, cross-checked, Windows (GNU) and macOS
  (aarch64); tests (paths, settings); Rust 1.85; run under Xvfb:
  screenshot, idle CPU 0 ticks in 10 s, memory in ADR 0004.

## Decisions

- glow renderer instead of wgpu (ADR 0004 updated). Reason: smaller,
  faster to build, less memory, and enough for transparent windows.
- ksni on Linux instead of `tray-icon`. Reason: `tray-icon` needs GTK and
  libappindicator at build and run time on Linux; ksni is pure Rust.
- No update check yet. Reason: it needs an HTTP client and TLS and depends
  on how the app is distributed (A9: winget, AppImage and Homebrew have
  their own update paths); it will be opt-in when it comes, since it
  contacts a server.
- Start hidden hides the window on the first frame, and only when a tray
  exists. Reason: the tray is known once the event loop runs.

## Open questions

- ADR 0004 acceptance: measurements with a GPU, on Wayland, Windows and
  macOS (owner's machines).
- The tray is untested (no D-Bus or tray host in the container), as are
  hiding and showing the window from it.
