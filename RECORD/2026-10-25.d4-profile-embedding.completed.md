# D4: Profile embedding and runtime overrides

- Status: completed
- Roadmap: ROADMAP/2026-10-14/ (task ID: D4)

## Goal

Embed curated device profiles (and SDL GameControllerDB bootstrap entries) at
compile time into a compact binary blob included via `include_bytes!`, loadable
without network access both natively and in WebAssembly (`.wasm`), while
supporting runtime overrides from user/game TOML files.

## Done

- `anygamepad_db::wire`: compact positional encoding (`encode_profiles`,
  `decode_profiles`) without `skip_serializing_if` so that `postcard`
  deserialization succeeds reliably without struct misalignment.
- `build.rs`: compiles curated profiles from `data/profiles/*.toml` into
  `OUT_DIR/curated.postcard`, and SDL GameControllerDB entries from
  `data/sdl-gamecontrollerdb/gamecontrollerdb.txt` into `OUT_DIR/sdl.postcard`.
  Emits `cargo:rerun-if-changed` for both data directories.
- `anygamepad_db::Database`: in-memory database with `Database::embedded()`,
  `Database::embedded_curated()`, `Database::empty()`, and
  `Database::with_profiles()`. Embedded profiles are lazily decoded once and
  shared via `Arc<[Profile]>`.
- Runtime overrides: `Database::load_override_toml(&mut self, &str)` and
  `Database::add_override(&mut self, Profile)`. Lookups via `best_match()`
  evaluate runtime overrides with precedence over embedded profiles on ties.
- `anygamepad::mapping::Mapper::from_database`: resolves the best matching
  profile for a `DeviceIdentity` directly against a `RawLayout`.
- WebAssembly bundle size budget: on `target_arch = "wasm32"`, SDL entries
  are omitted to preserve the 128 KiB bundle budget. The built `.wasm` bundle
  measures 105.9 KiB gzip (well within the 128 KiB limit).
- Tests: unit and integration tests covering embedding, curated vs SDL
  loading, precedence of overrides over embedded profiles, TOML validation,
  cloning, and `Mapper::from_database`. Passes `cargo fmt`, `clippy -D warnings`
  (native and wasm32), workspace tests, and Playwright smoke tests.

## Decisions

- **Dedicated wire format**: `postcard` encodes struct fields positionally
  without field tags and does not support `skip_serializing_if`. Rather than
  compromising `Profile`'s TOML formatting and JSON Schema, `anygamepad_db::wire`
  provides dedicated mirroring types (`CompactWireProfile`, `CompactWireRule`,
  `CompactWireMapping`, `CompactWireAxis`) without skipped fields.
- **Web bundle omits SDL GameControllerDB**: 2,279 SDL entries take 692 KiB
  uncompressed (~57 KiB gzip) in postcard format. Browsers never expose SDL
  indices (`indices = Sdl`), so embedding them in WebAssembly would consume
  ~57 KiB of the 128 KiB budget for zero browser capability. Native builds include
  both curated and SDL entries by default (`embedded-sdl` feature).
- **Runtime overrides precedence**: `Database::iter()` chains overrides before
  embedded profiles; since `best_match` keeps the first match on equal
  `MatchScore`, user/game overrides cleanly outrank built-in entries.
