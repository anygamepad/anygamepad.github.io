## Decisions

- Web app uses the library through WASM (owner decision). Reason: the web
  tester is a real consumer of the library and shares report-building code
  with the desktop app.
- Use all providers (native, web, SDL3, gilrs) behind per-device arbitration
  (owner direction). Reason: maximize the number of supported gamepads. Only
  one provider owns a device to avoid duplicates and competing handshakes.
  SDL3 and gilrs are optional Cargo features; SDL3 cannot run on
  `wasm32-unknown-unknown`, so the browser relies on the own web backend.
- Web has priority over desktop (owner decision). Modelled by gating the
  first desktop tasks on M2.
- Desktop UI: Tauri 2 recommended (reuse web frontend components); awaiting
  owner confirmation in ADR F3.
