# F3: Architecture decision records

- Status: WIP
- Roadmap: ROADMAP/2026-10-10/ (task ID: F3)

## Goal

Write the five ADRs listed in F3 and get them accepted by the owner.

## Done

- `docs/adr/0001` to `0005` written with status `proposed`, based on
  `docs/research/` (F2). ADR template gained an `Alternatives` section and an
  index.
- Main proposals:
  - 0001: positional names + label layer; Y positive = up (matches gilrs/Bevy
    and XInput; SDL3 and W3C use the opposite sign); SI units for motion;
    share/capture/mute as distinct buttons.
  - 0002: features `native` (default), `web` (wasm32), `sdl3`, `gilrs`;
    SDL-style ordered claims; SDL hints for coexistence; `hidapi` for HID.
  - 0003: TOML sources, Rust types + `schemars` as source of truth for the
    JSON Schema, `postcard` blob embedded at build time.
  - 0004: egui/eframe/wgpu, accepted only after a prototype meets measurable
    targets (idle CPU, memory, latency, widget behaviour).
  - 0005: Vite + TypeScript + Svelte 5 for the web UI, `wasm-pack --target
    web`, rAF loop outside the framework, `tsify`; server axum + sqlx +
    PostgreSQL.

## Decisions

- ADRs stay `proposed` until the owner accepts them. Reason: F3 is done when
  ADRs are accepted, and the stack choices are the owner's.

## Open questions

  alternatives).
- ADR 0004 needs the prototype measurements; it may be accepted later (desktop
  work starts after M2) without blocking C1, C2 and W1.

## Next steps
