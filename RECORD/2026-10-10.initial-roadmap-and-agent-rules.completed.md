# Initial roadmap and agent rules

- Status: completed
- Roadmap: ROADMAP/2026-10-10/ (all tasks defined here)

## Goal

Bootstrap the project documentation: define the agent rules, the first
roadmap with Gantt diagrams showing blocking tasks, and the RECORD memory
convention.

## Done

- `AGENTS.md`: project description, language rule (AGENTS, ROADMAP, RECORD and
  code comments always in English), session workflow, ROADMAP and RECORD
  conventions, code conventions.
- `CLAUDE.md`: only points to `AGENTS.md`.
- `ROADMAP/2026-10-10/`: overview (`README.md`) with master Gantt, dependency
  graph, milestones, risks; detailed files for foundations, core library,
  device database, collection pipeline, web app and desktop app.
- All Mermaid diagrams were validated by rendering them with mermaid-cli.

## Decisions

- Canonical model uses **positional** face buttons (South/East/West/North) plus
  a label/glyph layer, following SDL3. Reason: game logic must not depend on
  printed labels, which differ between Xbox, PlayStation and Nintendo layouts.
- Windows virtual output starts with ViGEmBus (Xbox 360, DualShock 4). An own
  virtual HID driver is deferred to "Beyond 0.1" because of driver signing
  cost and risk.
- The web tester (W1) only depends on the workspace scaffolding (F1) so it can
  ship early and start collecting data.
- Durations are calendar days and assume parallel workstreams; the dependency
  graph is the source of truth for ordering.
