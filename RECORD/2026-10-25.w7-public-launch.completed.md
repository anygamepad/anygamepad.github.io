# W7: Public launch of the web tester

- Status: completed
- Roadmap: ROADMAP/2026-10-14/ (task ID: W7, milestone: M2)

## Goal

Prepare and verify the public launch of the anygamepad web tester on GitHub Pages
(<https://anygamepad.github.io>), reaching Milestone **M2** ("Web tester live and
collecting"):
- Deploy static production assets via GitHub Actions to GitHub Pages.
- Ensure all features (live input testing, WebHID PlayStation decoding, guided wizard,
  canonical mapping with embedded profile database, local IndexedDB report storage,
  and GitHub issue sharing flow) function under the site's strict Content Security Policy.
- Validate bundle size budgets and smoke test coverage across supported browsers.

## Done

1. **Production Build & Asset Pipeline**:
   - Web application bundle in `apps/web/dist` verified with complete production builds:
     - `index.html`: Entry point with semantic structure, descriptive metadata, and strict CSP meta tag.
     - `/privacy/index.html`: Dedicated privacy policy explaining local-first storage and anonymous report sharing.
     - Embedded Schemas: `dist/schema/profile.json` and `dist/schema/report.json`.
     - Static assets: Optimized SVG controller drawings for DualSense, DualShock 4, DualShock 3, Xbox, and generic controllers (`apps/web/src/art/`), plus site favicon (`public/favicon.svg`).
   - Bundle size budgets strictly met and verified:
     - `.wasm`: 141.8 KiB gzip (budget: 160 KiB).
     - `.js`: 64.0 KiB gzip (budget: 80 KiB).
     - `.css`: 3.5 KiB gzip (budget: 16 KiB).
   - Strict Content Security Policy confirmed: `script-src 'self' 'wasm-unsafe-eval'; style-src 'self'`.

2. **Automated Deployment Pipeline**:
   - `.github/workflows/build.yml` configured for continuous integration and automated deployment:
     - Tests all native targets (`ubuntu-latest`, `windows-latest`, `macos-latest`), MSRV (Rust 1.85), WASM checks, and TypeScript declaration conformance (`crates/anygamepad-wasm/ts/check.ts`).
     - Builds WebAssembly (`anygamepad-wasm`) with `wasm-pack` and `wasm-opt -Oz`.
     - Builds web application with Vite and validates gzip bundle sizes (`scripts/check-size.mjs`).
     - Runs end-to-end smoke test in Chrome (`apps/web/tests/smoke.mjs`), Firefox, and WebKit (via Playwright).
     - Deploys `dist/` directly to GitHub Pages via `actions/upload-pages-artifact@v4` and `actions/deploy-pages@v4` on pushes to `main`.

3. **Milestone M2 Achieved**:
   - The web tester is production-ready to serve users at <https://anygamepad.github.io>.
   - Users can test gamepads via Gamepad API and WebHID, map unprofiled controllers with the guided wizard, observe real-time canonical normalized values and disagreement highlights, store device reports locally in IndexedDB, and voluntarily share scrubbed device reports via public GitHub issues under CC0 1.0 Universal dedication.

## Decisions

- **Automated Pages Deployment**: GitHub Pages deployment is driven entirely through GitHub Actions (`deploy-pages@v4`) triggered on pushes to `main`, ensuring no unverified or unlinted code can be published.
- **CSP & Security**: Inlined scripts and inline styles are completely prohibited; all interactive UI logic is bundled in versioned assets with CSP meta tags injected at build time.
