# F1: Cargo workspace, licensing, CI matrix

- Status: WIP
- Roadmap: ROADMAP/2026-10-10/ (task ID: F1)

## Goal

Empty Cargo workspace with the proposed layout, license, and CI on Linux,
Windows and macOS plus a WebAssembly build and headless browser tests.

## Done

- Workspace (`Cargo.toml`, edition 2024, resolver 3, `Cargo.lock` committed)
  with the six crates from the F1 layout: `anygamepad`, `anygamepad-model`,
  `anygamepad-db`, `anygamepad-report`, `anygamepad-virtual`,
  `anygamepad-wasm`. All at version `0.0.0` with crates.io metadata.
- Placeholders (README only) for `apps/web`, `apps/desktop`, `apps/server`,
  `data/profiles`, `docs/adr` (with the ADR template), `docs/research`.
- License `MIT OR Apache-2.0`: `LICENSE-MIT`, `LICENSE-APACHE`, README section.
- Workspace lints: `missing_docs`, `unsafe_op_in_unsafe_fn`, and clippy
  `undocumented_unsafe_blocks` (enforces the `// SAFETY:` rule of AGENTS.md).
  Crates that need no `unsafe` use `#![forbid(unsafe_code)]`.
- `rust-toolchain.toml` (stable + rustfmt, clippy, wasm32 target);
  `.cargo/config.toml` sets `wasm-bindgen-test-runner` as the wasm32 runner.
- `anygamepad-wasm` exports `version()` and has one `wasm-bindgen-test` test.
- CI (`.github/workflows/ci.yml`): fmt; clippy + test on ubuntu, windows,
  macos; wasm32 clippy + build + browser tests in headless Chrome and Firefox;
  MSRV check (`cargo +1.85 check`).
- Verified locally (Linux): fmt, clippy (native and wasm32), tests, MSRV 1.85
  check, and the wasm test in headless Chromium.

## Decisions

- License `MIT OR Apache-2.0`, as proposed in the roadmap. Reason: Rust
  ecosystem default, compatible with the zlib-licensed SDL GameControllerDB.
- MSRV 1.85 (first release with edition 2024); checked in CI.
- Browser tests use `wasm-bindgen-test-runner` installed at the exact
  `wasm-bindgen` version from `Cargo.lock` instead of `wasm-pack`. Reason: no
  extra tool in the loop, and the version can never drift.
- `apps/*` are not crates yet: W1, A1 and P2 create them with the stack chosen
  in F3.
- CI runs on every push (any branch) and on pull requests, so agent branches
  get CI before a PR exists.

## Open questions

- Safari browser tests (`safaridriver` on macOS runners) are not in CI yet.
- Name reservation with placeholder releases on crates.io and npm needs the
  owner's accounts. Each crate should also ship the license files when
  published.
